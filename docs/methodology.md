# 研究方法论

本文档记录项目的数据来源、清洗规则与统计分析方法。所有数值均可由 `notebooks/` 中的代码复现。

## 1. 问卷设计

### 1.1 维度设计

问卷围绕"目标用户群体的日常分期需求"这一主题设计，共 13 道题目，覆盖五个维度：

| 维度 | 对应题目 | 设计目的 |
|------|----------|----------|
| 基本信息 | 第 1 题（年龄） | 识别目标人群结构 |
| 消费行为 | 第 2、3 题 | 识别冲动消费倾向与非计划开销场景 |
| 分期态度 | 第 4、5、6、11、12 题 | 测量分期意愿、冷静期接受度、工具偏好、额度接受度 |
| 还款能力 | 第 7、8、9、10 题 | 测量生活费水平、可支配比例、分期使用历史、应急能力 |
| 渠道信任 | 第 13 题 | 测量对官方渠道的信任度 |

题型以单选题为主，第 3 题为多选题。选项设计参考了目标用户群体的典型消费场景（潮玩、服饰、旅游、文娱等）。

### 1.2 题目设置

| 题号 | 变量名 | 测量内容 |
|------|--------|----------|
| 1 | `age` | 年龄分段 |
| 2 | `impulse` | 冲动消费频率 |
| 3 | `scene` | 非计划开销场景（多选，7 个选项） |
| 4 | `demand_4` | 小额分期对购买意愿的影响 |
| 5 | `cooling` | 24 小时冷静期接受度 |
| 6 | `focus` | 分期管理工具最看重的功能 |
| 7 | `living` | 月生活费区间 |
| 8 | `disposable` | 可自由支配比例 |
| 9 | `installment_use` | 分期/信用消费使用历史 |
| 10 | `shortage` | 生活费不足时的应对方式 |
| 11 | `limit_accept` | 额度与用途限制接受度 |
| 12 | `demand` | 分期消费需求 |
| 13 | `trust` | 对官方渠道与电话推销的信任对比 |

## 2. 数据收集

### 2.1 样本来源

问卷通过在线问卷平台制作，经移动端渠道分发。样本来源覆盖华东、东北、华南等地区，同时覆盖全国多个省份，样本来源具有一定的地理分散性。

### 2.2 清洗规则

本次调查共回收问卷 127 份，经以下步骤清洗后保留有效问卷 100 份：

1. **剔除作答时间过短样本**：作答时间低于 10 秒的样本视为无效，剔除；
2. **剔除逻辑矛盾样本**：例如"从没用过分期"但"有过逾期"的样本，视为逻辑矛盾，剔除；
3. **随机抽样至 100 份**：为便于统计分析与报告呈现，从剩余有效样本中随机抽取 100 份作为最终分析样本。

清洗流程见图（由 `notebooks/01_data_cleaning.ipynb` 生成）：

```
回收问卷 127 份 → 剔除无效样本（作答过短、逻辑矛盾）→ 随机抽样至 100 份 → 有效样本 100 份
```

### 2.3 样本基本结构

| 维度 | 分布 |
|------|------|
| 年龄 | 19–22 岁 68%，23–28 岁 22%，18 岁及以下 10% |
| 月生活费 | 1500–2000 元 34%，2000–3000 元 30%，3000 元以上 19%，1000–1500 元 17% |
| 可支配比例 | 30% 以上 51%，10%–20% 26%，20%–30% 19%，10% 以下 4% |
| 冲动消费 | 74% 有倾向（偶尔 44% + 经常 30%），26% 自评理性 |
| 分期使用历史 | 从没用过 60%，用过已关掉 21%，用过且按时还 19% |

## 3. 分析方法

分析工具链：Python（pandas 清洗与频数统计，scipy 假设检验，statsmodels 回归，matplotlib/seaborn 可视化）。方法层面采用四类统计工具，形成从"样本描述"到"变量关系"再到"驱动因素"的递进分析路径。

### 3.1 描述统计

对月生活费与可自由支配比例两个连续变量计算均值、中位数、标准差、方差、偏度、峰度，刻画样本分布特征。

| 指标 | 月生活费（元） | 可支配比例 |
|------|----------------|------------|
| 样本量 | 100 | 100 |
| 均值 | 2222.5 | 26.7% |
| 中位数 | 1750 | 35% |
| 标准差 | 758.7 | 9.5% |
| 最小值 | 1250 | 5% |
| 最大值 | 3500 | 35% |
| 方差 | 575625 | 0.0091 |
| 偏度 | 0.496 | -0.634 |
| 峰度 | -0.901 | -0.999 |

解读：月生活费均值大于中位数，分布右偏，少数高生活费样本拉高了均值；可支配比例均值小于中位数，分布左偏。两者峰度均为负，分布比正态更平坦，样本内部差异明显。

### 3.2 卡方检验

用于判断两个分类变量之间是否存在显著关联，共检验六组变量：

| 变量对 | χ² | 自由度 | p 值 | 结论 |
|--------|-----|--------|------|------|
| 生活费 × 分期意愿 | 12.86 | 6 | 0.045 | 显著 |
| 可支配比例 × 分期意愿 | 5.78 | 6 | 0.448 | 不显著 |
| 冲动消费 × 冷静期接受度 | 13.93 | 4 | 0.008 | 显著 |
| 分期使用历史 × 冷静期接受度 | 5.30 | 4 | 0.258 | 不显著 |
| 年龄 × 分期使用历史 | 8.26 | 4 | 0.082 | 不显著 |
| 官方信任 × 分期意愿 | 20.41 | 4 | 0.0004 | 显著 |

三项关系显著：生活费等级影响分期意愿、冲动消费影响冷静期接受度、官方信任影响分期意愿。可支配比例和年龄不能作为授信分层的依据。

### 3.3 Spearman 相关分析

卡方检验只能判断"有没有关系"，Spearman 相关分析进一步测量有序变量之间的相关强度，共分析十个有序变量。关键组合如下：

| 变量对 | ρ | 强度 | 含义 |
|--------|-----|------|------|
| 分期使用历史 × 分期意愿 | 0.567 | 强正 | 用过分期的人意愿最强 |
| 应急能力 × 分期意愿 | -0.459 | 中等负 | 越依赖借钱越不愿分期 |
| 分期需求 × 分期意愿 | 0.430 | 中等正 | 有需求的人更愿分期 |
| 官方信任 × 分期意愿 | 0.372 | 中等正 | 越信任越愿分期 |
| 生活费 × 可支配比例 | 0.353 | 中等正 | 生活费越高可支配比例越高 |
| 生活费 × 分期意愿 | -0.318 | 中等负 | 生活费越高越不愿分期 |
| 冲动消费 × 分期意愿 | 0.318 | 中等正 | 越冲动越愿分期 |
| 冲动消费 × 冷静期接受度 | 0.264 | 弱正 | 越冲动越看重冷静期 |

### 3.4 多元线性回归

相关分析无法排除变量之间的相互干扰，进一步采用多元线性回归，在控制其他变量的条件下识别对分期意愿影响最大的因素。模型设定：

```
分期意愿 = β₀ + β₁×生活费 + β₂×可支配比例 + β₃×冲动消费
          + β₄×官方信任 + β₅×冷静期接受度 + ε
```

| 变量 | β | p 值 | 显著性 |
|------|-----|------|--------|
| 生活费 | -0.0002 | 0.063 | 不显著 |
| 可支配比例 | 0.418 | 0.580 | 不显著 |
| 冲动消费 | 0.228 | 0.018 | 显著 |
| 官方信任 | 0.302 | 0.0002 | 显著 |
| 冷静期接受度 | 0.155 | 0.118 | 不显著 |
| **R²** | **0.280** | | |
| 调整 R² | 0.242 | | |
| F 值 | 7.30 | 8e-06 | 显著 |

模型整体显著（F=7.30, p<0.001），解释力中等。官方信任（β=0.302）影响最大，冲动消费（β=0.228）次之。结论：分期意愿由信任和冲动驱动，而非生活费或可支配比例。

### 3.5 有序 Logit 回归

因变量为有序分类变量，以有序 Logit 回归作为稳健性检验，验证 OLS 结论的方向一致性。

## 4. 局限性

- 样本量为 100 份，统计功效有限，结论适用于方向性判断；
- 数据为自报告数据，冲动消费等变量依赖受访者主观评价；
- 可还款折算系数基于问卷数据标定，尚未经过真实还款数据验证。
