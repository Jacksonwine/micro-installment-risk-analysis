# 产品设计要点

本文档从数据分析视角总结微分期产品的核心设计决策，以及每条决策对应的调研证据。产品形态为连接目标用户群体日常消费场景与持牌金融机构的轻量化金融科技服务平台，核心设计逻辑是"无感接入、有感干预"。

## 1. 产品定位与形态

- **场景嵌入而非独立应用**：以标准接口形式嵌入票务、旅游、潮流电商、二手交易等高频消费平台的结算页面，用户在消费场景内即可完成身份认证、额度获取与分期支付，无需跳转或下载外部应用。依据：60% 的受访者从未使用过分期产品，独立应用形态获客成本高、留存率低。
- **极速身份认证替代传统开户**：首次使用时触发认证流程，通过官方渠道数据对接完成身份校验，实时下发专属额度。依据：受访者排斥繁琐的开户流程，期待"极速、无感"体验。

## 2. 用户流程

```
触达 → 实名认证 → 获得额度 → 分期支付 → 24h 冷静期 → 还款提醒 → 结清
```

流程图由 `notebooks/06_product_flow.ipynb` 生成（`results/charts/product_flow.png`）。

## 3. 核心功能一：24 小时无条件冷静期

- **界面**：分期支付完成后，订单详情页生成 24 小时冷静期倒计时模块，并提供一键退订按钮；
- **规则**：支付后 24 小时内可一键退订，交易全额取消，预付资金或额度原路退回，不收取任何违约金、手续费或利息；
- **设计依据**：74% 的受访者存在冲动消费倾向，且冲动消费与冷静期接受度显著相关（χ²=13.93, p=0.008）；60% 的受访者认为该机制能打消顾虑，仅 14% 表示不需要。该机制为冲动消费提供低成本反悔路径，并在逾期发生前前置化解潜在风险交易。

## 4. 核心功能二：智能还款测算与三色预警

确认分期支付前，系统强制弹出还款测算界面，展示分期总额、每期还款金额与还款时间表。用户输入月均生活费后，系统自动计算月还款负担比（每期还款额 ÷ 月均生活费），并触发分级预警：

| 预警级别 | 月还款负担比 | 系统动作 |
|----------|--------------|----------|
| 绿灯（健康区） | < 10% | 显示健康提示，允许顺畅支付 |
| 黄灯（预警区） | 10%–20% | 弹窗提示占用较多月度生活费，需手动勾选理性消费承诺框后方可继续 |
| 红灯（熔断区） | > 20% | 暂缓一键支付，主动推荐延长分期期数或取消本次分期 |

设计依据：将还款能力从抽象概念转化为用户可感知的具体数值，实现风险控制前置化。

## 5. 核心参数

### 5.1 额度体系（单笔控制 + 总量封顶）

| 参数 | 设定 | 说明 |
|------|------|------|
| 起投门槛 | 500 元 | 过滤零碎日常小额消费，避免账单碎片化 |
| 单笔上限 | 5000 元 | 覆盖票务、旅游、服饰、数码等典型消费区间 |
| 累计授信上限 | 10000 元 | 实时未还总本金达到上限即锁定新订单，杜绝多头借贷与额度膨胀 |

注：43% 的受访者不能接受上述限制，43% 持中立态度，仅 14% 能接受。因此风控措施需以"保护"而非"限制"的话术呈现。

### 5.2 分期期数与还款日

- 期数阶梯：3 期（500–1500 元）、6 期（1500–3000 元）、12 期（3000–5000 元）；
- 还款日：支持选择每月 5 日、10 日或 15 日作为统一还款日，首次还款顺延至下一个最近的指定日期，适配月初/月中集中获取生活费的资金流动特点。

### 5.3 计费模式（用户侧绝对零利息）

| 计费项目 | 收费标准 |
|----------|----------|
| 分期利息 | 0 元（商户贴息模式，无论 3/6/12 期均不向用户收取利息） |
| 开户与手续费 | 0 元（身份核验、授信评估、订单生成全程免费） |
| 提前还款手续费 | 0 元（支持随时一键全额结清或提前还清单期，无违约金） |
| 逾期 | 3 天宽限期内免收违约金，超时仅收极低滞纳金 |

账单拆算采用极简平摊公式：每期还款金额 = 订单总金额 ÷ 分期期数，计算结果精确到分，尾差自动计入最后一期，确认支付前在界面完整展示。

## 6. 分层授信

依据回归结论（还款能力取决于生活费与可支配比例），授信采用可还款余额模型并划分 A/B/C 三级，详细规则见 [risk_register.md](risk_register.md) 第 4.4 节。

## 7. 设计决策与调研证据对照

| 设计决策 | 调研证据 |
|----------|----------|
| 场景嵌入形态 | 60% 从未使用过分期产品 |
| 24 小时冷静期 | 74% 有冲动倾向；冲动×冷静期 p=0.008；60% 认可冷静期 |
| 三色预警（10%/20% 阈值） | 月生活费均值 2222.5 元、中位数 1750 元，低收入段占比高 |
| 单笔 500–5000、累计 10000 | 非计划开销集中在 500–5000 元区间商品 |
| A/B/C 分层授信 | 生活费×分期意愿 p=0.045；可支配比例不显著（p=0.448） |
| 四项一票否决 | 5% 存在借新还旧行为；21% 用过但已关掉 |
| "保护"话术替代"限制"话术 | 43% 不能接受额度限制 |
| 官方渠道合作 + 财商教育建立信任 | 官方信任 β=0.302（最强驱动）；52% 都怀疑官方渠道 |
