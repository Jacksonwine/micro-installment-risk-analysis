# 数据说明

## 目录

| 文件 | 说明 |
|------|------|
| `raw/survey_raw.xlsx` | 原始问卷数据：100 份有效样本的 13 道题作答（Sheet1） |
| `processed/survey_cleaned.xlsx` | 清洗与量化编码后的分析数据，由 `notebooks/01_data_cleaning.ipynb` 生成 |

## 隐私处理

`raw/survey_raw.xlsx` 在发布前已做脱敏处理：

- 仅保留 13 道题目的作答列，移除了问卷平台元数据列（序号、提交答卷时间、所用时间、来源、来源详情、来自 IP）；
- 第 13 题题干中的渠道表述已做泛化处理。

## 变量字典（raw）

| 变量名 | 对应题目 | 取值 |
|--------|----------|------|
| `age` | 第 1 题 | 18岁及以下 / 19-22岁 / 23-28岁 |
| `impulse` | 第 2 题 | 几乎没有，消费很理性 / 偶尔会有 / 经常有，经常不知不觉花超预算 |
| `scene` | 第 3 题（多选） | 7 个场景选项，原值为"┋"分隔的多选文本 |
| `demand_4` | 第 4 题 | 不会，不需要分期 / 可能会 / 会，极大降低了购买门槛 |
| `cooling` | 第 5 题 | 不需要 / 一般/无所谓 / 能，提供了一层很好的后悔与冷静机制 |
| `focus` | 第 6 题 | 绝对零利息、没有隐形套路 / 智能消费提醒与预算红线预警 / 支付后有24小时冷静期防冲动 / 场景覆盖多 |
| `living` | 第 7 题 | 1000–1500元 / 1500–2000元 / 2000–3000元 / 3000元以上 |
| `disposable` | 第 8 题 | 10%以下 / 10%–20% / 20%–30% / 30%以上 |
| `installment_use` | 第 9 题 | 从没用过 / 用过，但已经关掉/不再用了 / 用过几次，基本按时还 |
| `shortage` | 第 10 题 | 借新的钱来还旧的 / 找朋友或家人借 / 减少开支撑过去 |
| `limit_accept` | 第 11 题 | 不能接受 / 一般 / 能接受 |
| `demand` | 第 12 题 | 完全没有 / 几乎没有 / 偶尔有 / 经常有 |
| `trust` | 第 13 题 | 都怀疑 / 差不多 / 更信任 |

## 派生变量（processed）

| 变量 | 来源 | 说明 |
|------|------|------|
| `living_num` | `living` | 区间中值量化：1250 / 1750 / 2500 / 3500 |
| `disposable_num` | `disposable` | 区间中值量化：0.05 / 0.15 / 0.25 / 0.35 |
| `impulse_rank` | `impulse` | 有序等级 1–3 |
| `demand_rank` | `demand` | 有序等级 1–4 |
| `demand4_rank` | `demand_4` | 有序等级 1–3（回归因变量） |
| `cooling_rank` | `cooling` | 有序等级 1–3 |
| `trust_rank` | `trust` | 有序等级 1–3 |
| `installment_rank` | `installment_use` | 有序等级 1–3 |
| `shortage_rank` | `shortage` | 有序等级 1–3 |
| `limit_rank` | `limit_accept` | 有序等级 1–3 |
| `scene_<选项>` | `scene` | 多选题拆分的 7 个 0/1 变量 |

清洗规则（剔除作答时间 < 10 秒、剔除逻辑矛盾、随机抽样至 100 份）在问卷回收阶段完成，详见 [../docs/methodology.md](../docs/methodology.md)。
